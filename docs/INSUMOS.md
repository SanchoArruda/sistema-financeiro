# Inventário de insumos do projeto

| Arquivo | O que é | Usado pelo sistema em execução? | Onde será usado | Observações |
|---|---|---|---|---|
| `FSD.md` | Especificação Funcional e Técnica do projeto (FSD) | Não | Documentação / Orientação do desenvolvimento | Documento principal de especificação técnica, arquitetura, regras de negócio e banco de dados. |
| `DESIGN.md` | Especificação do Design System *Fiscal Precision* | Não | Documentação / Orientação visual (`assets/css/app.css`) | Define paleta de cores, tipografia Inter, espaçamentos, bordas, componentes e elevações. |
| `code.html` | Protótipo HTML/Tailwind da interface do Dashboard | Não | Referência visual para a construção das Views em Bootstrap | Protótipo de apoio com a estrutura do Dashboard. Utiliza Tailwind por conveniência de prototipagem, mas a aplicação utilizará Bootstrap local + `app.css` conforme FSD. |
| `screen.png` | Captura de tela / Mockup visual de referência do sistema | Pode precisar (a confirmar se contém assets gráficos) | Referência visual / Apoio de design | Imagem com o layout do Dashboard de referência visual. Caso sejam extraídos ícones/logos desta referência, os arquivos finais ficarão em `assets/img/`. |
